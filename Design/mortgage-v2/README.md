# 房贷 iOS UI · 第二版预览

这份可交互设计预览对应 `ClipStudio/Features/Mortgage*.swift` 的原生改版，不是模拟器截图，不进入 App，也不使用 WKWebView。

- 暖白 / 深色背景、松柏绿操作、圆角数字与更清楚的月供层级。
- 常驻底部导航、参数摘要与展开编辑、还款方式 / 提前还款策略对比。
- 本金与利息占比、剩余本金曲线、示例合同进度。
- 可切换浅色、深色与大字号；金额与策略复用 App 实际打包的计算资源。
- 当前合同和日期是明确标注的设计示例；不读取账户、本机草稿或云端方案，也不提供完整合同编辑。

在仓库根运行 `node Design/mortgage-v2/build.cjs`，然后打开生成的 `index.html`。它不需要网络资源。修改对应预览源文件后需重新生成。

原生实现、检查结果与 Xcode 验证边界见 `docs/mortgage-ui.md`。
