# 到手工资 iOS UI · 第一版预览

这是**已确认的设计稿**，不是模拟器截图，不进入 App，也不使用 WKWebView。SwiftUI 实现见 [到手工资界面与验证边界](../../docs/salary-ui.md)；后端应用目录与 Web 门厅没有改动，门厅卡片由 iOS 本地追加。

在仓库根运行 `node Design/salary-v1/build.cjs`，然后打开生成的 `index.html`。它不需要网络资源。修改预览源文件后需重新生成。

## 设计取向

「数字工资条」：暖纸底 `#f2f1ea` + 深墨绿 `#10635a`，到手金额与税前去向之间用一条带打孔缺口的撕线分隔。五笔钱的流向各有固定色（到手绿 / 公积金琥珀 / 社保蓝 / 个税红 / 其他紫），图表、占比条、工资条与对比页共用同一套色，深色模式有完整对应 token。数字使用等宽圆体，便于逐月对齐比较。

## 三个页签

1. **到手试算** — 工资条式首屏（本月到手 + 资金去向占比 + 全年到手 / 月均 / 全年个税），下方是**常驻展开**的参数台：城市、税前月薪、社保与公积金基数口径、公积金比例、专项附加扣除、年终奖与发放月、其他税前 / 税后扣款、入职月份。滚动超过一屏后顶部浮出迷你结果条，改参数时结果始终可见。再往下是 12 个月堆叠柱状图，标出跳档月份，可点选或键盘切换到某一月。
2. **逐月工资条** — 月份横条 + 应发项目 / 个人扣除 / 实发到手的收据式明细，可展开单位缴纳部分看公司总成本；下方「本月个税怎么来的」逐项列出累计收入、累计减除费用、累计三险一金、累计专项附加、累计应纳税所得额、累计应纳税额、此前已预扣与本月应预扣，并给出算式。支持复制文本与导出。
3. **对比** — 年终奖「单独计税 vs 并入综合所得」自动择优与跳档盲区提示（含「多发多少才能真的多拿」的解法）、两份 offer 的全年到手对比与落袋比例、涨薪边际试算、全年这笔钱去哪了。

## 算法口径

`salary.js` 是纯计算引擎，预览页、检查脚本与 App 共用同一份源码：`ClipStudio/Resources/Salary/salary.js` 与本目录的 `salary.js` 逐字节一致，由 `scripts/check-native.py` 断言。原生桥接层是 `ClipStudio/Resources/Salary/salary-bridge.js`。

- 工资个税走**累计预扣预缴法**，不是按月近似：年初 3% 档、跳档后到手逐月变小，这是本设计要讲清楚的核心。
- 三险一金按当地基数上下限截断，医疗含城市固定额，工伤 / 生育个人不缴，公积金比例 0–12%。
- 专项附加扣除按现行标准（子女教育 / 婴幼儿 2000 每孩，赡养老人独生 3000、分摊 1500，房贷 1000，房租 1500 / 1100 / 800，继续教育 400，个人养老金 ≤1000 每月）。
- 年终奖单独计税按「奖金 ÷ 12」查按月换算表，政策执行至 **2027-12-31**（财政部 税务总局公告 2023 年第 30 号）；同时算并入综合所得，自动取全年税额更低者。
- 不含劳务报酬、股权激励、经营所得、公益性捐赠、大病医疗汇算扣除与年度汇算补退税。

**城市预设的社保 / 公积金上下限是明确标注的示例值**，页面上可直接改；正式接入前须按当地社保年度公布数据核对。默认演示场景（上海 / 月薪 32,000 / 公积金 7% / 年终奖 60,000）同样是示例，不读取账户、本机草稿或云端数据。

## 检查

在仓库根运行，只需 Node 内置模块：

```bash
node Design/salary-v1/check.cjs           # 52 条计算断言
node Design/salary-v1/check-browser.mjs   # 62 条真实浏览器断言 + 截图
```

`check-browser.mjs` 用 CDP 驱动本机 headless Chrome / Edge（`CHROME_PATH` 可覆盖），覆盖首屏渲染、参数台实时联动、逐月图表、工资条、对比页、跳档盲区、弹层、滚动迷你条、深色、320px 大字号、超长整页截图与反复交互稳定性，结果写入 `verification.json`，截图输出为 `preview-*.png`。

`preview-*.png` 是**浏览器渲染的设计预览截图，不是 iOS 模拟器截图**。原生实现、XCTest 与模拟器截图的验证边界见 [到手工资界面与验证边界](../../docs/salary-ui.md)。
