# 公开快照说明

公开主分支从整理后的当前源码和新的根提交开始，不引用此前的提交历史。旧 Actions 运行记录在重建时清理；历史重建不能保证 GitHub 缓存、旧 SHA 链接或已被保存的副本完全消失。

## 包含

- 完整的原生应用、阅读框架、资源、单元测试与 UI 用例。
- 有数、房贷的原生改版与现有账户/加密/云同步接口。
- 测试向量、DEBUG 示例数据和本地敏感信息检查。
- 只读敏感信息检查工作流、手动 iOS 构建与源码一致性验证流程。

## 不包含

- 旧仓库的提交历史、作者邮箱元数据和本机 Git 配置。
- 旧 Actions 链接、日志、截图、构建产物、发布历史或审查报告。
- 个人服务器默认地址、实际账户令牌、签名私钥或本机数据。
- 被忽略的环境文件、数据库、缓存、日志、生成工程和 IPA。

阅读模块的逐文件来源哈希与有意修改清单保留，以维护实现来源与完整性；这些清单不包含来源仓库的 Git 历史对象。

## 运行时与安装身份

首次登录需填写自己的 HTTPS 工作台根地址。公开版本采用 `com.example.workbench`，阅读框架使用 `com.example.workbench.reader`，Keychain service 使用同一中性应用标识。它作为独立新 App 安装，旧 App 的沙盒和 Keychain 不会自动迁移；本机阅读库和未同步草稿需要另行处理，不能视为已经迁移。旧 App 不会被删除，云端账号数据也不会被清空。未签名 IPA 仍须自行签名。

生产内容密钥使用系统安全随机数创建；测试中的固定密钥仅用于验证协议兼容性，DEBUG 示例数据不会作为生产账号发布。

## 后续公开内容

新 Actions 的日志、截图和 IPA 也属于公开内容。只使用隔离的测试账号与示例数据，不要将真实服务会话、私人信息或签名材料写入工作流。敏感信息检查只报告位置与类型，不打印匹配值。

当前没有替所有者选择 MIT、Apache 等许可证。需要明确授予他人复用权限时，应先确认自有及第三方代码的授权范围。
